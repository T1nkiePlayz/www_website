AETHERIA
// overview

A world built to explore.

Aetheria is my largest game-development project and a long-term attempt to build something much bigger than a traditional prototype. The goal is a multiplayer 2D ARPG where exploration, progression, combat, systems and the world itself all contribute to the experience.

Rather than treating the world as a sequence of fixed levels, I'm interested in creating a place that supports discovery, experimentation and reasons to return.

// world

Exploration and systems.

Procedural generation, different environments, transportation and environmental features are all areas of the world design. The project has to work at both large scale — regions, travel and world structure — and small scale, such as resources, encounters and interactable objects.

// gameplay

Systems that connect.

Character progression, combat, abilities, factions, exploration and world interactions are intended to influence one another. This makes architecture important: the code needs to stay understandable as new mechanics are added.

// multiplayer

Shared exploration.

Multiplayer is part of the project's direction from the beginning. That affects how game state, characters, interactions and persistence need to be structured, with the aim of making shared exploration feel natural while preserving meaningful individual progression.

// learning

Learning while building.

Aetheria gives me a reason to study software architecture, object-oriented programming, game systems, persistence and networking while dealing with the practical problems of a growing codebase.

// long_term

A project measured in years.

The scope is ambitious, so development is about building solid foundations and learning how to manage scope rather than rushing through a feature checklist.

// project_note

More than just a big game.

Aetheria is also an opportunity to learn how to design, structure and maintain a large software project. Every system is teaching me something that can carry into future work.
