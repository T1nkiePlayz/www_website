// how_i_build

Projects are a way to learn.

I don't expect every project to become a finished product. Building something forces me to deal with structure, debugging, iteration, scope, documentation and decisions that only appear once a project becomes bigger than a prototype.

That is especially useful in game development, where code, design, art, systems and content all need to work together.
